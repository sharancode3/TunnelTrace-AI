# RFC 8247
## Algorithm Implementation Requirements and Usage Guidance for the Internet Key Exchange Protocol Version 2 (IKEv2)

**Authority:** Internet Engineering Task Force (IETF)  
**Publication Date:** September 2017  
**Status:** APPROVED / ACTIVE / PROPOSED STANDARD  
**Document Code:** RFC 8247  
**URL:** https://datatracker.ietf.org/doc/html/rfc8247  

---

### Section 2.1 IKEv2 Encryption Algorithms
RFC 8247 specifies cryptographic algorithm requirements for IKEv2 SAs:
- `ENCR_AES_GCM_16` (AES-GCM with 128 or 256-bit keys and 16-octet ICV): MUST be supported.
- `ENCR_AES_CBC` (AES in CBC mode with 128 or 256-bit keys): MUST be supported for backward interoperability.
- `ENCR_3DES_CBC` (Triple-DES): MUST NOT be used due to Sweet32 collision vulnerabilities.
- `ENCR_DES`: MUST NOT be used.

### Section 2.4 Diffie-Hellman Key Exchange Groups for IKEv2
RFC 8247 defines required Diffie-Hellman groups for IKE_SA_INIT:
- `Group 14` (2048-bit MODP): MUST be supported.
- `Group 19` (256-bit random ECP, NIST P-256): MUST be supported.
- `Group 1` (768-bit MODP) and `Group 2` (1024-bit MODP): MUST NOT be used due to vulnerability to discrete logarithm precomputation attacks.
